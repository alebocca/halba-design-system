MethodBadge labels an HTTP method in 12px DM Mono: GET on `sky-tint`, POST on `success-tint`, PUT and PATCH on `warning-tint`, DELETE on `danger-tint`, text in `ink`. The word is the meaning; the tint only groups.

`Endpoint` puts the badge and the path on one `surface-raised` line (`<Endpoint method="POST" path="/v1/payments" />`); the path is selectable and scrolls on narrow screens. Use it under the page title of every reference page.
