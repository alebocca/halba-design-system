StatTile is a big flat colour block with one proof number and a caption, used on the marketing site.

Provide `value` (the number, already formatted) and `label` (one line). Pick `tone` from brand, accent, sky, brand-tint, sun (light yellow), sky-tint (light blue) or ink; `lavender` and `azure` still work as older names for brand-tint and sky-tint.

- Place at most three tiles in a row and give each a different tone.
- Keep `value` under 8 characters so it stays on one line at the `stat` style; below 900px the number drops to `stat-sm` (64px) by itself.
- Text colour is set by the tile (`on-brand`, `on-accent`, `on-sky`, `ink`); do not override it.
- Use one `accent` tile per page at most.
