Button triggers an action; it is a pill (`radius-pill`) and comes in primary, accent, secondary and ghost styles.

Provide a short verb-first label as `children`. Add `withArrow` for navigation actions such as "Get in touch".

- Use one `primary` button per view; use `accent` only for a single high-priority promotion on the site.
- Use `secondary` next to a primary for the lesser choice, and `ghost` for toolbar actions.
- Keep the label to 1–3 words in sentence case.
- Do not use `accent` and `primary` side by side.
- Disabled buttons show `surface-sunken` with `ink-muted` text; explain why nearby.
