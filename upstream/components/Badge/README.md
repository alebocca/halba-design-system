Badge is a small mono uppercase status label such as LIVE, RECONCILED or 2 CONFLICTS.

Provide the word as `children` and pick a `tone`. Every badge carries a word, because colour alone must not carry status.

- `success` (green) for OK: Approved, Reconciled, Rescued. `warning` (yellow) for Challenge, Medium risk and Needs review. `danger` (red) for KO: Declined, Failed, Fraud, High risk. `brand` for highlights, `neutral` for everything else.
- Name the state with the same word everywhere (for example always "Challenge", never "3DS check" in one place and "Verify" in another).
- Keep text under three words and let the component uppercase it.
- Do not use badges as buttons.
